Version control systems such as Git are widely used in software development.
State two advantages of using version control when writing software. Explain each point from:
• the perspective of an individual programmer;
• the perspective of working in a team developing software.

State one disadvantage of Git. You can write this from either:
• your own perspective;
• the perspective of a new programmer who has just been introduced to it.
You may use external resources to help you, but answers must be written in your own words.


Advantages of using version control as an individual programmer is that it allows you to keep track of all of your changes and how the program has developed. This is especially important when developing, as if a mistake is made, a programmer can revert back to an earlier version instead of losing work. This is especially important in a team environment, where version control allows everyone to see what has changed, when and who has changed it. This makes identifying problems and bugs a lot easier, especially if different programmers have been assigned separate tasks. Furthermore, using version control allows for working on new features on separate branches, without affecting the main project. This allows for safe experiment and helps keep any new feature changes organized. In a team setting, this allows multiple developers to work on the same software without accidentally overwriting other's work. This makes it easier to merge different pieces of code and manage changes as a team.

A disadvantage of using git as a new programmer is the discipline required to keep on top of version control. As a new programmer, they may be more used to saving changes directly to the file they are working on rather than committing changes to a remote repository. This can result in moments where they accidentally save directly to a the file, and if an error occurs and they need to revert to an older version, they will lose lots of progress.
